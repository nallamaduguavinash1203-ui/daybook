Daybook final build

Includes:
- Courses and topic planning
- Topic import and review
- Exams
- Daily goals
- Events and reminders
- Timetable image OCR and review/edit
- Today scheduling timeline
- Live Maps-style schedule notification bar
- During the final 10 minutes of a current class/learning block, the bar switches to the next scheduled class/learning block and shows its start countdown
- Responsive UI and animations

This package contains the frontend source files to replace in the existing Vite React project.
